# Copper Kettle · landingspagina

Landingspagina voor de theecampagne van Copper Kettle, onderdeel 6 van het schoolproject *Marketing campagne automatisatie* (Elias Dellaert, DVG2C).

- Hero, merkverhaal, de vier smaken, campagnefilm en theemomenten
- Ingebed MailerLite-inschrijfformulier (naam, e-mail, opt-in) dat de mailflow start
- Beelden gemaakt met Figma Weave (Gemini 3 / Nano Banana Pro) op basis van de productfoto's
- Gebouwd als één HTML-bestand met Claude (vibe coding), gehost op GitHub Pages
